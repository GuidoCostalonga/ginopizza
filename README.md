# ginopizza.it

Il dominio "ginopizza.it" è un nickname da chat degli anni '90 (modem 56k, 1994) portato avanti come una "croce" personale per oltre 30 anni.

Oggi ci sta sopra il sito di Guido Costalonga, assessore alla Sicurezza, Protezione Civile,
Patrimonio e Mobilità Sostenibile del Comune di Roveredo in Piano (Pordenone).
Tono satirico sul soprannome, sostanza amministrativa rigorosa sui contenuti.

Sito statico: cinque pagine HTML, un foglio di stile, uno script e un'immagine vettoriale.
Nessuna dipendenza esterna, nessun passaggio di compilazione, nessuna raccolta di dati personali.

Le pagine **non si modificano a mano**: si modifica `costruisci.py` e si rigenera con

```
python3 costruisci.py
```

Documentazione completa, elenco delle fonti e istruzioni di pubblicazione: [LEGGIMI.md](LEGGIMI.md).

Questo non è il sito istituzionale del Comune di Roveredo in Piano.
Gli atti che fanno fede sono quelli pubblicati all'albo pretorio del Comune.
